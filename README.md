## 🔐 Microsoft Entra ID & Intune Zero Trust Security Lab

Built a hands-on Microsoft security lab combining identity protection, authentication security, endpoint security, device encryption and Conditional Access.

The project demonstrates how Microsoft Entra ID and Microsoft Intune can work together to make access decisions based on both user identity and device security state.

### Skills demonstrated:

- Microsoft Entra Conditional Access
- Multi-Factor Authentication
- Emergency Access Administration
- Temporary Access Pass
- Self-Service Password Reset
- Password Writeback
- Passkey Authentication
- Authentication Strength
- Phishing-Resistant MFA
- Microsoft Defender Antivirus
- Windows Defender Firewall
- Attack Surface Reduction
- BitLocker
- TPM
- Device Compliance
- Microsoft Intune
- PowerShell
- Windows Event Viewer
- Sign-In Log Analysis
- Zero Trust Access Control
- Troubleshooting & Root-Cause Analysis

### Troubleshooting highlights:

**SSPR Password Writeback**

Investigated a failed password reset for a synchronized Active Directory user, identified that Password Writeback was not configured in Microsoft Entra Connect, enabled the required functionality and successfully retested SSPR.

**BitLocker Silent Encryption**

Investigated BitLocker protection remaining disabled even though the Intune policy had reached the endpoint. BitLocker Event ID 853 identified bootable installation media attached to the Hyper-V virtual machine. After removing the Windows installation ISO and restarting the endpoint, BitLocker protection was successfully enabled and recovery information was verified.

**Zero Trust Device Compliance**

Created a controlled compliance failure by temporarily raising the minimum Windows OS requirement. The device became noncompliant and Conditional Access blocked the user's access. After correcting the requirement and allowing Intune to reevaluate the endpoint, compliance and user access were restored.
